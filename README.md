# karga-veri

Karga uygulamasının veri katmanı. GitHub Actions kaynakları düzenli okur, normalize JSON üretir,
GitHub Pages statik API olarak sunar. Uygulama yalnızca bu JSON'u okur.

**Faz 0:** `Actions → probe → Run workflow` ile GitHub runner'ından kaynaklara erişim test edilir.
Sonuç iş özetinde (Summary) bir tablo olarak görünür.
